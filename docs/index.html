Caveman Skill

AI 에이전트 답변을 반복 업무용 신호로 압축하는 커뮤니케이션 스킬.

일반 답변 이 문제는 인증 미들웨어에서 토큰 만료 시간을 비교하는 조건이 잘못되어 발생한 것으로 보입니다.
Caveman 답변 Auth middleware bug. Expiry check use < not <=. Fix condition.

Why It Matters

반복 작업에는 짧은 결론이 더 강하다

1 상태 보고 완료, 막힘, 다음 행동이 바로 보인다.
2 코드 리뷰 문제 위치와 수정 방향이 흐려지지 않는다.
3 오류 분석 원인, 영향, 검증 명령을 짧게 연결한다.
4 토큰 절약 부가 효과. 핵심은 비용보다 작업 속도다.

Rules

말투는 줄이고 정보는 남긴다

좋은 압축은 설명을 없애는 게 아니라 잡음을 제거한다.

제거 예의 문구, 반복 표현, 불필요한 hedging, 긴 접속어.
유지 기술 용어, 코드, 에러 메시지, 경로, 명령어.
형식 문제 -> 원인 -> 수정 -> 검증 순서로 짧게 정리.

Use Cases

어디에 좋고 어디에 나쁜가

✓ 좋은 상황
코드 리뷰 테스트 실패 요약 git diff 상태 보고 PR 코멘트 초안 터미널 오류 해석
! 주의할 상황
초보자 교육 보안/법무/고객 문안 되돌릴 수 없는 명령 실행 복잡한 의사결정 설명 감정적 피드백

Pattern

실무에서는 이 형태가 좋다

짧아도 순서는 유지해야 오해가 줄어든다.

Root cause: env var missing.
Impact: DB connect fail.
Fix: add DATABASE_URL in deploy secret.
Verify: run health check.

Fact Check

75% 절감보다 중요한 것

공개 자료는 출력 토큰 절감을 강조하지만, 교육 메시지는 비용보다 작업 속도와 인지 부하 감소에 둔다.

결론: Caveman은 말투 장난이 아니라, 반복적인 에이전트 작업에서 답변을 업무용 신호로 압축하는 방식이다.
