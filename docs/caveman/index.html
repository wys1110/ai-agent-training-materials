Caveman Skill · 03 / 05

말 한 마디면 된다

트리거 표현 중 하나를 말하면 즉시 활성화. 끄기 전까지 대화 내내 유지된다.

켜기"caveman mode" / "be brief" / "less tokens" / "짧게" / /caveman
끄기"stop caveman" / "normal mode" / "자세히 설명해줘"

이럴 때 효과적이다

반복 디버깅 에러를 연속으로 잡을 때. 긴 설명을 읽을 여유가 없다.
빠른 API 확인 파라미터·타입만 필요할 때. 배경은 필요 없다.
코드 리뷰 짧고 정확한 피드백이 필요할 때.
토큰 절약 긴 컨텍스트 유지하면서 응답 길이를 줄일 때.

Caveman Skill · 04 / 05

위험할 때는 자동으로 상세해진다

짧게 말하면 안 되는 순간에는 caveman을 잠깐 벗어나 명확하게 경고한 뒤, 자동으로 돌아온다.

보안 경고 — 취약점·인증 문제는 반드시 상세히 되돌릴 수 없는 작업 — DROP, DELETE, 파일 삭제 순서가 중요한 절차 — 단계를 잘못 이해하면 문제 생기는 작업 반복 질문 — 같은 질문을 다시 하면 상세 설명으로 전환 
위험 작업 예시:

> **Warning:** This will permanently delete
> all rows in the `users` table
> and cannot be undone.
>
> ```sql
> DROP TABLE users;
> ```
>
> Verify backup exists first.

Caveman resume.

Caveman Skill · 05 / 05

한 마디로 대화 밀도가 바뀐다

Caveman은 단순히 "짧게 말해"가 아니다. 기술 정확도를 유지하면서 읽는 시간을 4배 줄이는 구조적 압축이다.

지금 바로 써보기대화창에 "caveman mode" 또는 "짧게"라고 입력하면 즉시 시작된다.
스킬 파일 설치SKILL.md를 Claude 설정에 추가하면 /caveman 슬래시 커맨드로도 켤 수 있다.

한 문장 요약

스킬은 "프롬프트 모음"이 아니라, 에이전트가 특정 상황에서 반복적으로 같은 품질의 행동을 하도록 만드는 규격이다. Caveman은 그 중 가장 즉각적인 효과를 체감할 수 있는 스킬이다.
